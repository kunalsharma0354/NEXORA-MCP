# Project AI Context

This folder is a template for the `.ai/` directory that the skill creates inside a project.

## Suggested files

- `PROJECT.md` — verified project summary and stack.
- `ARCHITECTURE.md` — major modules and data flow.
- `CONVENTIONS.md` — observed coding conventions.
- `COMMANDS.md` — verified development and test commands.
- `TASK_CONTEXT.md` — current task, affected files, plan, and checks.
- `DECISIONS.md` — durable technical decisions and rationale.
- `KNOWN_ISSUES.md` — confirmed issues and unresolved questions.

Only create files that are useful for the actual project. Never store secrets or copy large source files into this folder.
